# Projects Directory

This folder contains detailed documentation and code for individual data analysis projects.

## Project Structure

Each project folder should include:
- `README.md` - Project overview and findings
- `data/` - Sample or demo data (large files excluded via .gitignore)
- `notebooks/` - Jupyter notebooks with analysis
- `scripts/` - Python scripts for data processing
- `visualizations/` - Charts, graphs, and dashboards
- `reports/` - Final reports or presentations
