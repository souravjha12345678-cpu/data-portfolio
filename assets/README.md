# Assets Directory

This folder contains images, charts, dashboards, and other visual assets for the portfolio.

## Contents

- **images/** - Screenshots, logos, and other images
- **charts/** - Exported charts and graphs (PNG, SVG)
- **dashboards/** - Dashboard screenshots or exports
- **presentations/** - Slide decks and presentation materials

## File Naming Convention

Use descriptive names with lowercase and hyphens:
- `sales-dashboard-overview.png`
- `customer-segmentation-chart.png`
- `healthcare-metrics-report.pdf`

## Formats

- Images: PNG, JPG, SVG
- Documents: PDF, PPTX
- Data visualizations: PNG, SVG (for embedding in README)
