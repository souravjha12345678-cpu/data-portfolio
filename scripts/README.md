# Scripts Directory

This folder contains Python scripts for data processing, analysis, and automation.

## Contents

- **Data Extraction** - Scripts to extract data from various sources
- **Data Cleaning** - Automated data cleaning and preprocessing
- **ETL Pipelines** - Extract, Transform, Load processes
- **Analysis Scripts** - Reusable analysis functions
- **Automation** - Scheduled tasks and automated reports

## Usage

Run scripts from the command line:
```bash
python script_name.py
```

Or import functions into notebooks:
```python
from scripts.data_cleaning import clean_dataset
```

## Requirements

Install dependencies:
```bash
pip install -r requirements.txt
```
