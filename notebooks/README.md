# Notebooks Directory

This folder contains Jupyter notebooks for exploratory data analysis, visualizations, and data experiments.

## Contents

- **Exploratory Data Analysis (EDA)** - Initial data exploration notebooks
- **Data Cleaning** - Data preprocessing and transformation notebooks  
- **Visualizations** - Chart and graph creation notebooks
- **Statistical Analysis** - Statistical testing and modeling notebooks

## How to Use

1. Install required packages: `pip install -r requirements.txt`
2. Launch Jupyter: `jupyter notebook`
3. Open any `.ipynb` file to view the analysis

## Best Practices

- Use clear markdown cells to explain your analysis
- Include visualizations and insights
- Document your thought process
- Keep notebooks focused on a single analysis topic
